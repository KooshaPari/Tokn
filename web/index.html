Token analytics for LLM workloads

Cost calculation, pricing book management, and intelligent provider routing — pure Rust, no I/O dependencies.

Cost calculation

Compute per-token cost across OpenAI, Anthropic, Google, and custom providers. 

use pareto_rs::cost::compute_cost;
let c = compute_cost("openai", "gpt-4o", 1000, 500).unwrap();

Pricing book

Manage model pricing across providers. Reload from disk on the fly. 

use pareto_rs::models::PricingBook;
let book = PricingBook::load("pricing.toml")?;

Provider routing

Pick the best model for the job based on price, latency, and quality scores. 

use pareto_rs::pricing::decide_route;
let r = decide_route(&book, "fast", 0.5);

Plugin system

Hook into cost/pricing/routing with custom plugins. Three built-ins included. 

use pareto_rs::plugin::default_registry;
let reg = default_registry(); // 3 hooks loaded
